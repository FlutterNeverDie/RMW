description: 장면표의 언어별 더빙 대사를 현지화 가이드 기준으로 검토하고 고친 뒤 검토 도장을 찍는다
argument-hint: episodes/<편>/ep.json [언어...]
---

현지화 검토 하네스. 대상: $ARGUMENTS (언어를 안 주면 장면표 langs 중 영어 빼고 전부)

1. `docs/guide/02-제작-결정.md`의 언어 항목과 `docs/guide/locales/<언어>.md`를 읽는다. 가이드가 없는 언어면 같은 형식으로 먼저 만들고 사용자에게 알린다
2. `python3 scripts/check-text.py <장면표>`로 규칙 오류부터 확인
3. 언어마다 `python3 scripts/locale-review.py lines <장면표> <언어>`로 줄을 뽑고, 언어가 둘 이상이면 언어마다 서브에이전트를 하나씩 동시에 띄워 검토한다. 각 서브에이전트에게는 가이드 전문과 줄 목록을 주고, 이 기준으로 줄마다 본다:
   - 그 나라 유튜버가 실제로 쓸 말인가 (직역투·번역투·어색한 어순·관용구 직역)
   - 가이드의 말투·존댓말·2인칭이 통일됐나
   - 영어 원문과 뜻이 같나 (빠진 정보, 틀린 숫자·연도·이름)
   - 이름이 `episodes/names.json` 표기인가
   - 영어보다 눈에 띄게 길지 않나 (장면 길이 = 가장 긴 언어 → 영어 원본에 빈 시간이 생김)
   - 결과는 줄 번호 · 문제 · 고친 문장만, 문제 없는 줄은 적지 않는다
4. 고친 문장을 장면표 i18n에 반영한다 (영어·화면·순서는 건드리지 않는다). 사용자가 판단 못 하는 언어라 고칠 때 이유를 한 줄씩 남긴다
5. 다시 `check-text.py`를 돌려 오류 0 확인 후, 언어마다 결과를 `{"ok": true, "summary": "...", "fixed": ["#12 이유", ...], "left": ["판단이 필요한 것", ...]}`로 scratchpad에 쓰고 `python3 scripts/locale-review.py stamp <장면표> <언어> <파일>`
6. 사용자에게 언어별로: 고친 줄 수, 대표적인 고친 예 2~3개(전/후와 이유, 한국어로 설명), 남은 판단거리. 한국어는 사용자가 직접 들을 수 있으니 고친 문장을 다 보여 준다
