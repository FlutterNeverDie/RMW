Use case 설명

HMW Uploader is a private command-line tool that I, the owner of the History Map World channel, run on my own computer. It uploads videos that I make about my own website (historymapworld.com, a free interactive world history map) to my own channel only. It uses videos.insert with the youtube.upload scope to upload a finished MP4 with its title, description, tags and an optional publishAt time, and channels.list (youtube.readonly) to confirm the authorized channel. It does not access any other user's data, does not display YouTube data to anyone, and stores nothing except my own OAuth refresh token locally on my machine. The tool has exactly one user (me). I am requesting the audit so that videos uploaded through the API are not locked to private and so that scheduled publishing (status.publishAt) works.

API 기능 / 데이터 처리 질문이 나오면

API methods: videos.insert (resumable upload), channels.list (mine=true). Scopes: https://www.googleapis.com/auth/youtube.upload, https://www.googleapis.com/auth/youtube.readonly Data stored: only my OAuth refresh token, in a local file readable only by my OS user. No YouTube API data is stored, shown or shared. Quota: about 2-5 uploads per week; the default 10,000 units/day is enough.

심사 중 데모 영상(화면 녹화)을 요구하면, 터미널에서 node scripts/youtube.mjs upload …를 실행해 스튜디오에 영상이 올라오는 장면을 찍어 보내면 됩니다. 필요하면 제가 같이 만듭니다.
