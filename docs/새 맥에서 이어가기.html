새 맥에서 이어가기

코드는 GitHub(FlutterNeverDie/RMW), 열쇠·Claude 기억은 AirDrop, 큰 파일(영상·더빙·목소리 캐시)은 이 맥에 그대로 둔다.

1. 이 맥에서

  1. ~/hwm/코드/scripts/pack-handoff.sh → 바탕화면 hwm-옮길것 폴더 (열쇠 4개 + Claude 기억)
  2. 그 폴더를 AirDrop. 옮긴 뒤 폴더와 사본은 지우기 (유튜브 업로드 권한이 들어 있음)

2. 새 맥에서

mkdir -p ~/hwm && cd ~/hwm
git clone https://github.com/FlutterNeverDie/RMW.git 코드
cd 코드 && ./setup.sh
  1. 받은 secrets/ 파일 → ~/hwm/코드/secrets/, 그리고 chmod 600 ~/hwm/코드/secrets/*
  2. 받은 claude-memory/*.md → ~/.claude/projects/-Users-<사용자이름>/memory/
  3. ./setup.sh를 다시 돌려 "열쇠 있음" 4줄 확인
  4. cd ~/hwm && claude → CLAUDE.md와 docs/guide/를 읽고 이어감

3. 쇼츠만 만들 때 필요한 것

  • 지도 캡처는 저장소에 들어 있음 (public/clean). 새 연도·지역이 필요하면 사이트(chronomap) 로컬 서버를 켜고 scripts/clean.mjs
  • 브금·효과음은 저장소에 들어 있음. 목소리는 처음 만들 때 TTS를 다시 부름 (무료 한도 안)
  • 렌더 결과는 새 맥의 ~/hwm/쇼츠에 쌓임 - 이 맥과 자동으로 합쳐지지 않으니 필요하면 AirDrop

주의

  • 열쇠는 git·클라우드에 올리지 않기 (.gitignore로 막혀 있음)
  • 두 맥에서 동시에 같은 편을 고치지 말기 - 끝나면 커밋·푸시, 시작 전 git pull
  • 공유 Claude 계정이라 claude.ai 원격 세션은 쓰지 않기
