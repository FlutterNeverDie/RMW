# 만드는 법

## 폴더 (`~/hwm`)
```
hwm/
├── 영상/<재생목록>/<N편 - 한글 부제>/   영상·썸네일 3개·한국어/스페인어 더빙·업로드 정보.html
├── 쇼츠/ 배너/ 홍보/ 브금/ tts/ API 감사 자료/
├── 채널 운영 정리.html
└── 코드/   ← 이 저장소
```
- 산출물은 직접 옮기지 않고 `deliver.json`에 넣고 `node scripts/deliver.mjs`
- 경로에 한글이 있으니 스크립트에서 `URL.pathname` 대신 `fileURLToPath`

## 한 편 만들기
1. 조회수 높은 같은 주제 영상 분석 (원칙 1)
2. 그림 받기: `commons_get` 방식으로 퍼블릭 도메인만, credits.json 기록
3. 지도 캡처: 사이트 로컬 서버(`chronomap`에서 `npx next dev`) + `SITE=http://localhost:3000 node scripts/clean.mjs <세트> 2560x1440 "<휠>^x,y@dx,dy" <연도...>` (본 지도는 10년 단위로 끊긴다)
   크기는 기본 2560x1440. 장면표 확대 z는 `캡처 폭(크기×2) ÷ 2560` 이하 - 넘으면 흐려짐, 더 당길 곳은 휠 확대 세트를 따로 캡처 (02 지도 선명도 규칙)
4. 장면표 `episodes/<시리즈>-<NN>/ep.json`: 장면마다 role·text·i18n(ko,es)·show(map/art/lapse/title/stamp/line/units/endcard)·music
   새 인물·지명은 `episodes/names.json`에 언어별 표기 추가 → `python3 scripts/check-text.py episodes/<편>/ep.json`
   인물 캐릭터: `python3 audio/characters.py list episodes/<편>/ep.json` → 설계 없는 인물을 Claude가 `characters.json`에 그려 넣고 `python3 audio/characters.py build`
   대사 카드(line)는 말하는 사람 캐릭터가 자동으로 나오고, 지도·그림 장면은 `"char": "<id>"`로 세운다
5. `src/Root.tsx`에 컴포지션 등록 (timeline.json import)
6. **`scripts/make-episode.sh episodes/<편>/ep.json <컴포지션> out/<편>.mp4`**
   대본 검사(걸리면 멈춤) → 목소리(모든 언어) → 화면 잘림 검사 → AI 음성 검수 → 렌더 → **깜빡임 검사**(걸리면 멈춤) → 더빙 트랙 → deliver
7. 썸네일 3개(`src/episode/Thumb.tsx`, Root에 Still 등록) → deliver
8. `episodes/<편>/meta.json` → `python3 scripts/upload-info.py` → 편 폴더에 업로드 정보.html

## 편집기 (AI 없음, 내 맥에서만)
- `npm run editor` → http://localhost:4600. 위에서 재생목록 > 편을 골라 한 편씩 연다
- 캡컷식 배치: 가운데 영상(실제 렌더와 같은 Episode를 Remotion Player로 소리까지 재생), 아래 트랙(화면·인물·효과음·브금·언어별 대사), 오른쪽 장면 속성, 왼쪽 언어 타이밍·대본 검사
- 트랙 장면을 누르면 그 위치로 이동. 장면 오른쪽 끝을 끌면 `hold`(장면 끝 여유, 모든 언어 공통). Space 재생, ←→ 장면 이동, ⌘S 저장
- **언어 타이밍**: 유튜브 더빙은 화면 하나 + 언어별 소리라 장면 길이 = 가장 긴 언어. 대사 트랙 막대 = 그 언어 길이(초록 꽉 참 / 노랑 침묵 1.2초+ / 빨강 침묵 2.5초+), 점선 = 목소리 만들기 전 글자 수 어림. 혼자 긴 언어는 줄이고 침묵이 긴 언어는 늘려서 맞춘다 → 목소리를 만들기 전에 맞추면 TTS 한도를 아낀다
- `audio/voice_episode.py`가 timeline.json에 언어별 실제 길이(`dur`)를 남기고 `hold`를 더한다
- **소리 넣기**: 오른쪽 "소리" 탭에서 미리듣기 → 트랙에 끌어다 놓거나 + (재생 위치에). 효과음은 장면 안 시점으로 `cues: [{src, at, vol}]`에 저장, 브금은 놓은 장면부터 `music`. 효과음 클립은 끌어서 옮기고 Delete로 지움
- 내 소리 파일(mp3·wav 등)은 소리 탭이나 트랙에 끌어다 놓으면 wav로 바꿔 `public/sfx/my/`(효과음)·`public/bgm/`(브금)에 저장 (Remotion에 든 ffmpeg 사용)
- **인물**: 넣고 빼는 건 편집기에서 안 한다 - Claude가 시나리오(장면표)를 쓸 때 `char`·말하는 사람으로 정함. 편집기는 화면 탭에서 위치(왼쪽·가운데·오른쪽)·포즈·보는 방향만 다듬고, 트랙 인물 우클릭 → 캐릭터 모습 고치기(색·모자·옷 등, 다시 그리기)
- **업로드한 편**: `meta.json`에 `"uploaded": "날짜"` → 편집기가 화면·장면 순서·길이·영어 대사·인물을 잠금, 미리보기도 올린 영상 그대로(인물 없음). 더빙 대사·효과음·브금만 고친다(아직 안 올린 더빙 트랙용). 더빙 대사가 장면보다 길면 빨강
- 트랙 클립 우클릭: 효과음 삭제·듣기, 전환음 끄기, 브금 바꾸기 해제, 장면 복제·삭제, 캐릭터 모습 고치기
- **카메라**: 화면 탭에서 시작·끝의 x·y·확대를 슬라이더·숫자로. 그림 실제 크기를 읽어 확대 한도(그림 폭 ÷ 2560, 그림은 화면에 맞춘 폭 기준)를 넘으면 빨강 경고
- ⌘Z 되돌리기 / ⇧⌘Z 다시 하기 (글자 칸 밖에서). show 칸은 입력 중에 다시 정렬하지 않음
- 자막(.srt)은 문장마다 그 언어 목소리 길이를 글자 수 비율로 나눔. 목소리 만든 뒤 대사가 바뀐 곳은 알려 줌
- 업로드한 편 잠금은 서버 저장에서도 확인 (더빙 대사·효과음·브금 말고 바뀌면 거부)
- 미리보기 그림·영상 파일(/api/still·/api/clip, `src/preview.tsx`), 자막 .srt(목소리 만든 뒤), 캐릭터 모아보기·다시 그리기도 여기서

## 업로드 (스튜디오, 감사 통과 전엔 직접)
0. (채널에서 한 번) 설정 → **채널 → 고급 설정 → 자동 더빙 → "자동 더빙 허용" 체크 해제** (업로드 기본 설정 아님). 켜져 있으면 유튜브가 20개 넘는 언어로 AI 더빙을 만들어 우리 더빙과 섞인다 (04 참고)
1. 영상 업로드, 영어 제목·설명·태그 (업로드 정보 페이지 복사 버튼)
2. 썸네일 1번 기본, 2·3번은 테스트 및 비교
3. 변경되거나 합성된 콘텐츠: 예 (AI 목소리)
4. 재생목록에 넣기
5. 언어 → 한국어·스페인어: 제목·설명 + 더빙 트랙
6. 최종 화면: 마지막 20초 점선 자리에 다음 편 + 구독 (다음 편이 없으면 최신 업로드)
7. 카드: 이전 편을 언급하는 시점에 이전 편 카드
