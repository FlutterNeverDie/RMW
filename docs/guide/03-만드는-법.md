## 폴더 (`~/hwm`)
```
hwm/
├── 영상/<재생목록>/<N편 - 한글 부제>/   영상·썸네일 3개·한국어/스페인어 더빙·업로드 정보.html
├── 쇼츠/ 배너/ 홍보/ 브금/ tts/ API 감사 자료/
├── 시안/   그림체 등 고르기 전 시안
└── 채널 운영 정리.html
```
- 코드는 이 저장소(`~/Documents/GitHub/RMW`)에만. 예전 `~/hwm/코드`는 안 씀 (2026-10-21). 산출물 폴더는 저장소 위치와 상관없이 `~/hwm` (`HWM` 환경 변수로 바꿀 수 있음)
- 산출물은 직접 옮기지 않고 `deliver.json`에 넣고 `node scripts/deliver.mjs`
- 경로에 한글이 있으니 스크립트에서 `URL.pathname` 대신 `fileURLToPath`

## 한 편 만들기
전체 단계·담당·게이트는 **06-제작-단계.md** (`python3 scripts/pipeline.py status episodes/<편>/ep.json`). 아래는 각 단계의 실제 명령
1. 조회수 높은 같은 주제 영상 분석 (원칙 1)
2. 그림 받기: `commons_get` 방식으로 퍼블릭 도메인만, credits.json 기록
3. 지도 캡처: 사이트 로컬 서버(`chronomap`에서 `npx next dev`) + `SITE=http://localhost:3000 node scripts/clean.mjs <세트> 2560x1440 "<휠>^x,y@dx,dy" <연도...>` (본 지도는 10년 단위로 끊긴다)
   크기는 기본 2560x1440. 장면표 확대 z는 `캡처 폭(크기×2) ÷ 2560` 이하 - 넘으면 흐려짐, 더 당길 곳은 휠 확대 세트를 따로 캡처 (02 지도 선명도 규칙)
4. 장면표 `episodes/<시리즈>-<NN>/ep.json`: 장면마다 role·text·i18n(ko,es)·show(map/art/cutout/lapse/title/stamp/line/units/endcard)·music
   `mapscene` = 기울인 지도 + 부대 애니메이션: `{scene: "<장면 이름>"}` → 장면 파일 `episodes/<편>/maps/<장면>.json`. 목소리를 만든 뒤 사이트 개발 서버(`chronomap`에서 `npx next dev`)를 켜고 `node scripts/map-scene.mjs --scene episodes/<편>/maps/<장면>.json --frames <timeline의 그 장면 frames>` → `public/ep/<편>/maps/<장면>/00000.jpg…`. 목소리를 다시 만들면 다시 찍기 (marks만 고치면 대사 순간에 맞춰짐)
   `art`에 `parallax: 0.06` = 옛 그림 2.5D (렌더 전에 `scripts/scene-frames.py`가 목소리 길이만큼 찍음 - make-episode.mjs가 부름)
   `cutout` = 옛 그림을 찢은 종이처럼 지도 위에: `{map, mapFrom, mapTo, img, from, to, box:[x,y,너비,높이](화면 비율), rot}` - 말하는 캐릭터(`char`)와 같이 쓰면 A+B 화면 (02 인물 캐릭터)
   새 인물·지명은 `episodes/names.json`에 언어별 표기. 장면 필드: `char`·`pose`·`facing`·`charAt`(인물), `cues`(효과음), `hold`(끝 여유)
   캐릭터: `python3 audio/characters.py list <장면표>` → `characters.json`에 설계 → `python3 audio/characters.py build <id>` (대사 카드는 말하는 사람 캐릭터가 자동)
   **인물 움직임 필드 (2026-10-21)** - 대사 카드(`line`)와 지도·그림 위 인물(`char`) 모두:
   - `gesture`: `point`(가리킴)·`fist`(주먹)·`open`(두 손 펼침) - 팔이 아래에서 올라와 말하는 동안 살짝 움직임. `gestureAt`(초) = 올라오는 시점(기본 등장 직후)
   - `enter`: `up`(기본, 아래서 늘었다 줄며 올라옴)·`pop`(튀어나옴)·`none` / `exit`: `down`·`pop`(장면 끝 0.4초에 퇴장, 기본 없음)
   - `beat`: `jump`·`shake`·`hop`·`sink`·`nod`·`none` - 없으면 포즈 따라 자동(shocked 펄쩍, angry 부르르, happy 통통, sad 가라앉음). `beatAt`(초)
   - 과하지 않게: 한 장면에 손짓 하나, 반응은 감정이 바뀌는 대사에만
   **장 카드 (`title`, 2026-10-21 글자 없는 판)**: `{type:"title", year:1219}`(연도 + 그 해에 가까운 10년의 제국 영역) · `{part:2}`(편 첫 카드, 로마 숫자) · 둘 다 주면 편 번호는 작은 테 · `years:"1162-1227"` · `focus:[x,y,z]`(지도 초점) · `series`(기본 mongol). 예전 `title`·`sub` 낱말은 그리지 않고 숫자("1219", "PART 2")만 뽑아 씀. 지도 재료는 `.venv/bin/python -I scripts/title-art.py <시리즈>` → `public/series/<시리즈>/`(이름 없는 지도 + 10년 단위 세트에서 제국 색만 뽑음). 새 시리즈는 `scripts/title-art.py`의 SERIES·DECADES와 `src/episode/Cards.tsx`의 SERIES(상징 그림)에 추가
   **최종 화면 (`endcard`)**: 글자 없이 ▶ + 다음 편 번호(`nextPart`, 없으면 예전 `next` 글의 "Part 3"에서 숫자만) + 구독 칸 아래 종. 칸 자리는 그대로
5. `src/Root.tsx`에 컴포지션 등록 (timeline.json import)
6. **`node scripts/make-episode.mjs episodes/<편>/ep.json <컴포지션> out/<편>.mp4`** (맥은 `scripts/make-episode.sh …`도 같음, `--dry-run`이면 단계·명령만 보여 줌)
   대본 검사(걸리면 멈춤) → 현지화 검토 도장(없으면 멈춤 - 먼저 Claude에게 `/localize episodes/<편>/ep.json`) → 목소리(모든 언어) → 화면 잘림 검사 → AI 음성 검수 → 렌더 → **깜빡임 검사**(걸리면 멈춤) → 더빙 트랙 → deliver
7. 썸네일: `episodes/<편>/thumbs.json`(변형 3개 × 언어별 문구) → `node scripts/thumbs.mjs episodes/<편>/thumbs.json` (Still `Thumb` 하나로 언어마다 찍어 편 폴더·meta.json에)
   자막: `scripts/subtitles.py`가 목소리의 실제 쉼에 문장 경계를 맞춰 언어별 `.srt` (make-episode.mjs 끝, 편집기 "자막 파일" 버튼도 같은 것)
8. `episodes/<편>/meta.json` → `python3 scripts/upload-info.py` → 편 폴더에 업로드 정보.html

## 편집기 (AI 없음, 내 컴퓨터에서만 - 맥·윈도우)
- `npm run editor` → http://localhost:4600. 쓰는 법은 사용자 설명서 `docs/편집기-사용법.html`(→ `~/hwm/편집기 사용법.html`) - **편집기를 고치면 설명서도 같이 고치고 deliver**
- 코드: `scripts/editor.mjs`(서버, 화면 코드 `editor/app.tsx`를 esbuild로 묶음) · `editor/index.html`(스타일) · `src/preview.tsx`(설명 영상 `src/docs/Pipeline.tsx`용). 검사는 `POST /api/check`가 저장 안 한 장면표를 모든 검사기(`--stdin --json`)에 넣어 칸마다 오류로
- 서버 코드를 고치면 `pkill -f scripts/editor.mjs` 후 다시 켜야 함. 서버는 Host·Origin을 확인해 다른 웹페이지의 요청을 막음
- 저장 = 장면표 + `영상/<재생목록>/<편>/편집/MMDDhhmm-이름.json` 편집본, 저장 직전 상태는 `episodes/<편>/.history/`(git 제외)
- 업로드한 편(`meta.json` `"uploaded"`)은 화면·순서·길이·영어·인물 잠금 (서버 저장에서도 거부). 유튜브에서 지우면 그 줄도 지움

## 업로드
`node scripts/youtube.mjs upload out/<편>.mp4 uploads/<편>.json` (먼저 `--dry-run`으로 보낼 내용 확인): 영상 + 영어 제목·설명·태그 + **한국어·스페인어 제목·설명** + **썸네일 1번** + 합성 콘텐츠 표시, 올린 뒤 `meta.json`에 `uploaded`·`youtubeId`. 스튜디오에 남는 것: 더빙 오디오 트랙(API 없음), 자막·재생목록(권한 밖), 썸네일 2·3번 비교, 최종 화면·카드. API 감사 통과 전엔 비공개로 잠김
0. (채널에서 한 번) 설정 → **채널 → 고급 설정 → 자동 더빙 → "자동 더빙 허용" 체크 해제** (업로드 기본 설정 아님). 켜져 있으면 유튜브가 20개 넘는 언어로 AI 더빙을 만들어 우리 더빙과 섞인다 (04 참고)
1. 영상 업로드, 영어 제목·설명·태그 (API, 또는 업로드 정보 페이지 복사 버튼)
2. 썸네일 1번 기본, 2·3번은 테스트 및 비교
3. 변경되거나 합성된 콘텐츠: 예 (AI 목소리)
4. 재생목록에 넣기
5. 언어 → 한국어·스페인어: 제목·설명 + 더빙 트랙
6. 최종 화면: 마지막 20초 점선 자리에 다음 편 + 구독 (다음 편이 없으면 최신 업로드)
7. 카드: 이전 편을 언급하는 시점에 이전 편 카드

## 시네마틱 장면 (2026-10-21)
- 장면표: `{"type": "cinematic", "shot": "<샷>"}` → 샷 파일 `blender/shots/<샷>.json` (지역 `terrain.center`·`extent_km`·`cell_m`, 카메라 키 `t`(0~1)·`lon`·`lat`·`agl`(땅 위 m)·`heading`·`pitch`·`roll`·`lens`, `sun` 방위·고도, `haze`, `clouds`, `rivers`, `palette`, `grade`)
- 목소리 다음 `scripts/scene-frames.py`가 Blender로 그 장면 길이만큼 찍는다 → `public/ep/<편>/<편>/cinematic/<NN>/00000.jpg…` (샷 파일·길이·blender 코드가 같으면 건너뜀)
- 직접 찍기 (윈도우는 Blender 경로만 `node scripts/tools.mjs`에 나오는 것으로): `/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P blender/render_shot.py -- --shot blender/shots/<샷>.json --out <폴더> --frames N` (`--scale 0.5 --only 0,120,239`로 반 크기 몇 장만 먼저 보고 고친다)
- 처음엔 `blender/prep_terrain.py`(.venv)가 고도 조각을 받아 굽는다(1~2분, `data/geo/terrarium`·`data/geo/cinematic`에 캐시, git 밖). 렌더는 M2에서 프레임당 약 3.5~4초(2560×1440, 16샘플)
- 새 샷 고를 때: 카메라는 산과 10~40 km 거리, 땅 위 1~3 km가 웅장하게 보임. 너무 낮으면 앞 땅이 흐리고 평평한 들판만 보임, 너무 멀면 산이 안개에 묻힘. 해는 카메라 옆~앞옆(정면 뒤는 밋밋)

## 윈도우 PC (2026-10-21 사용자 결정: WSL 없이 윈도우에서 바로)
- 설치: 저장소 폴더에서 **`setup.cmd`** (더블클릭 또는 터미널) → `setup.ps1`이 setup.sh와 같은 순서로 winget(Git·Node LTS·Python 3.13·Chrome·Blender·VC++ 런타임·7-Zip)·npm ci·.venv·깊이 모델·Rhubarb·sfizz·fluidsynth·VSCO·MuseScore sf2·브금 렌더·효과음 원본·`~/hwm` 폴더·열쇠 확인. 다시 돌려도 됨. 끝에 `node scripts/tools.mjs`·`scripts/tools.py`가 찾은 도구 위치 표를 찍는다 ("없음"이 없어야 함)
- 실행: `node scripts/make-episode.mjs episodes/<편>/ep.json <컴포지션> out/<편>.mp4`, 편집기 `npm run editor`, 파이썬은 `.venv\Scripts\python -I scripts\...` (윈도우의 `python3`는 스토어 바로가기라 쓰지 않음 - `pipeline.py`가 할 일 글에 .venv 파이썬을 적어 줌)
- 외부 프로그램 위치는 한 곳: `scripts/tools.mjs`(Node)·`scripts/tools.py`(파이썬). 기본 자리 - 크롬 `C:\Program Files\Google\Chrome\Application\chrome.exe`(또는 `%LOCALAPPDATA%`), Blender `C:\Program Files\Blender Foundation\Blender <버전>\blender.exe`(가장 새 것), `%USERPROFILE%\src\rhubarb\rhubarb.exe`·`src\sfizz\bin\Release\sfizz_render.exe`·`src\fluidsynth\bin\fluidsynth.exe`, ffmpeg는 Remotion에 든 것. 다른 자리면 환경 변수 `CHROME`·`BLENDER`·`SFIZZ_RENDER`·`RHUBARB`·`FLUIDSYNTH`·`RMW_PYTHON`·`HWM`
- 새 코드 규칙 (맥·윈도우 둘 다 돌게): 외부 프로그램 경로는 tools에서만 가져온다(`/Applications`·`~/src`·`.venv/bin` 직접 쓰지 않기). `npx`를 코드에서 부르지 않는다 - `tools.remotion(...)`(노드로 remotion-cli.js를 바로, 윈도우 npx.cmd는 cmd를 거쳐 `--props` 따옴표·한글 경로가 깨짐). 파일 열기는 `openPath`(맥 open, 윈도우 start). 크롬 인자는 `ANGLE`(맥 metal, 윈도우 d3d11). 셸 파이프(`| tail`)로 단계를 잇지 않는다 (make-episode.mjs가 안에서 줄임)
- 한글: 윈도우 파이썬 기본 인코딩이 cp949라 setup.ps1이 `.venv`에 `scripts/win-sitecustomize.py`를 넣어 늘 UTF-8 모드(`-X utf8`)로 돈다 + 사용자 환경 변수 `PYTHONUTF8=1`. 맥에는 안 깔림
- sfizz는 윈도우만 공식 릴리스 1.2.3 실행 파일(맥은 최신 소스 빌드)이라 브금 소리가 맥과 미세하게 다를 수 있다. 맞춰야 하면 `setup.cmd -BuildSfizz`(MSVC Build Tools + CMake로 소스 빌드 → `SFIZZ_RENDER` 등록)
- 줄 끝은 `.gitattributes` (`*.sh` LF, `*.ps1`·`*.cmd` CRLF). `setup.ps1`은 UTF-8 BOM으로 둘 것 (PowerShell 5.1이 BOM 없으면 한글을 깨뜨림)
