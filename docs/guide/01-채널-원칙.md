# 채널 원칙 (사용자 확정, 2026-10-20)

세계사 채널이다. 사이트(historymapworld.com) 홍보 채널이 아니다 - 사이트 지도는 영상 품질을 올리는 재료일 뿐, 영상·설명·배너를 광고처럼 만들지 않는다.

1. 잘나가는 영상을 찾아서 비슷하게 만든다 - 기획 전에 같은 주제의 조회수 높은 영상 구조를 분석한다
2. 브금은 웅장하게 (에픽·오케스트라 계열)
3. 나라마다 왕조가 어떻게 바뀌는지에 집중해서 나라별로(시리즈로) 올린다
4. 10분 정도로 끝나는 나라별 역사 또는 전투 양상 (나폴레옹 등)
5. 유튜브 설정에 채널 키워드 넣기 (알고리즘)
6. 초반 5초가 판가름 - 초반엔 말도 빠르게, 바로 훅. 오프닝 로고 없이 스크롤하는 손을 붙잡는다
7. 썸네일 반드시 넣기
8. 화면은 쉬지 않는다 - 3~5초마다 지도 확대·이동, 진군 표시, 인물 등장, 그림 컷. 화면은 그대로인데 목소리만 바뀌는 구간 금지
9. 브금은 채널 전용으로 직접 만들어 여러 곡을 돌려 쓴다 (메인 테마·전투·긴장·비가·승리)
10. 내레이션·대사는 연기가 있어야 한다(과하지 않게). 느린 목소리는 절대 금지, 너무 빠르지도 않게 - 적당히 빨라서 재밌고 몰입되게

그 밖에
- 업로드 주기보다 한 편의 품질이 우선
- 대본은 위키백과를 베끼지 않고 새로 쓴다 (CC BY-SA, 유튜브 재사용 콘텐츠 판정)
- 인물 대사는 사료를 바탕으로 극화. 실제 기록에서 온 말은 대본에 [기록] 표시, 논란 있는 숫자는 "chroniclers claimed"처럼 말한다
