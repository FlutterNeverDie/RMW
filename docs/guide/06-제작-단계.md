# 제작 단계 (2026-10-20 사용자 확정)

한 편은 아래 단계를 차례로 조립해서 만든다. 메인은 Claude, 판단이 필요 없는 일은 코드(토큰 없음), 사용자는 세 번 확인하고 마지막에 편집기로 다듬는다.
실행기: `python3 scripts/pipeline.py status|run|ok episodes/<편>/ep.json` - 어디까지 됐는지, 다음이 누구 차례인지 알려 주고 코드 단계는 `run`이 자동으로 돌린다.

| # | 단계 | 담당 | 통과 조건 (게이트) |
|---|---|---|---|
| 0 | **기획**: 잘된 영상 분석 (사용자가 준 영상 + 별별역사 등 직접 찾기) | Claude | `episodes/<편>/plan.md` |
| 1 | **대본** (영어) | Claude | 장면표 |
| 2 | **재미 보강**: 첫 5초 훅·빠른 줌아웃, 멈춘 화면 나누기, 질문·반전 | Claude | `check-pacing.py` (원칙 4·6·8) |
| ✋ | **확인 1: 대본** - 한국어 요약 + 재미 포인트 | 사용자 | `pipeline.py ok ... ok1` |
| 3 | **화면 재료**: 위키미디어·오픈 이미지(퍼블릭 도메인, credits.json), 지도 캡처 | 코드+Claude | 그림 있음, `check-screen.py` |
| 4 | **화면 연출**: 카메라·캐릭터·오린 그림(`cutout`)·기울인 지도 장면(`mapscene`, 한 편 3~5번) | Claude | `check-screen.py` 확대 한도, 화면 글자 규칙(숫자·연도·기호만) |
| 5 | **나라별 언어** | Claude | 모든 언어 대사 |
| 6 | **언어 다듬기** | Claude (언어별 서브에이전트) | `check-text.py` + 검토 도장 (`/localize`) |
| 7 | **길이 맞추기**: 더빙 ≤ 영어 110% | 코드가 찾고 Claude가 고침 | `check-length.py` |
| 8 | **효과음·브금 자리** | Claude (전환음은 코드 규칙) | `ok ... sound` |
| 9 | **캐릭터 만들기**: 설계(ko·about 포함) → 그림 | Claude+코드 | 모든 인물 설계·그림 있음 |
| ✋ | **확인 2: 캐릭터** - 편집기 인물 탭 | 사용자 | `ok ... ok2` |
| 10 | **목소리** + 끝 잡음 검사 + 입 모양 | 코드 (Google TTS + Gemini) | `check-voice.py` |
| 11 | **렌더** (1440p) + 잘림·깜빡임 검사 + 더빙 트랙. 먼저 `mapscene` 장면을 목소리 길이대로 찍기(`map-scene.mjs`) | 코드 | `make-episode.sh` |
| ✋ | **확인 3: 편집기** - 보고 고치기(편집본 저장) → 고치면 렌더 다시 | 사용자 | `ok ... ok3` |
| 12 | **썸네일·업로드 정보** | Claude 문구 + 코드 | `uploads/<편>.json` |
| 13 | **업로드** (API, `youtube.mjs`) | 코드 | `meta.json` `"uploaded"` |

## 원칙
- **사용자 확인 3번은 편집기에서** - Claude가 편집기를 그 편으로 열어 주고(`http://localhost:4600/?e=<편>`) 멈춘다. 사용자가 편집기에서 고치고 저장하면 그 내용으로 이어감
- **도장은 본 내용의 지문**을 담는다 (`episodes/<편>/pipeline.json`, `review/<언어>.json`). 앞 단계가 바뀌면 뒤 도장이 저절로 풀린다 - 대본을 고치면 확인 1·언어 검토·길이·목소리를 다시
- **Claude는 게이트에 걸린 곳만 고친다** - 코드 검사를 Claude 단계 사이에 둬서 토큰을 아낀다. 전체를 다시 읽고 다시 쓰지 않는다
- 캐릭터 그림·입 모양·검사·렌더는 코드라 토큰이 들지 않는다
- 업로드는 API로 (`youtube.mjs`, `uploads/<편>.json` 그대로) - 영상·언어별 제목·설명·태그·썸네일 1번까지. 더빙 트랙·자막·재생목록·최종 화면은 스튜디오 (03 업로드). 감사 통과 전엔 비공개로 잠김

## Gemini 목소리 (무료, 모델당 하루 10번)
- 인물 대사 연기와 AI 음성 검수에 쓴다 (사용자: 품질 괜찮음). 결과는 캐시돼서 같은 대사는 다시 부르지 않는다
- `scripts/gemini-tts.mjs`가 하루 사용량을 기록(`audio/.gemini-usage.json`)하고, 다 쓴 모델은 부르지 않는다. 남은 양: `node scripts/gemini-tts.mjs quota`
- 한도가 차면 Chirp가 대신하고 `voice_episode.py`가 그 줄을 알려 준다 → 다음 날 다시 돌리면 캐시 덕에 남은 줄만 Gemini로 채운다
- 아껴 쓰기: 연기가 필요한 배역(cast.json `direction`)만 Gemini. 내레이터는 Chirp
- **유료 전환 (결정 2026-10-20, 적용은 사용자가 원할 때)**: 연기 대사만 유료, 내레이션은 계속 Chirp 무료. gemini-3.8-flash-tts 기준 편당 약 60~100원(2027년부터 2배). 바꾸는 법: 사용자가 AI Studio에서 그 프로젝트에 결제 연결 + 월 예산 알림 → `touch secrets/gemini_paid` (하루 한도 기록을 끄고 하루에 끝냄). 되돌리려면 그 파일 삭제

## 주간 흐름 (5~7일에 한 편, 2026-10-20 사용자)
- 병목은 목소리(Gemini 무료 하루 20번)뿐이고 1~2일이면 끝남. 그동안 Gemini가 필요 없는 일을 병행
- `pipeline.py status`의 목소리 줄이 "연기 N번 필요 · 오늘 남은 M번 → 약 D일"을 알려 줌

| 날 | 이번 편 | 같이 할 일 |
|---|---|---|
| 1 | 기획 · 대본 · 재미 보강 → ✋확인 1 | |
| 2 | 화면 · 언어 · 길이 · 소리 · 캐릭터 → ✋확인 2 → 목소리 1일차 | |
| 3 | 목소리 2일차 → 렌더 → ✋확인 3 | 쇼츠 (이번 편 재료, Gemini 안 씀) |
| 4 | 썸네일 · 업로드 | 다음 편 기획 · 대본 |
| 5~7 | 공개 대기 | 쇼츠, 다음 편 화면 · 캐릭터 |

- **두 편의 목소리 단계를 같은 날 하지 않는다** (하루 한도를 나눠 씀). AI 음성 검수는 다른 모델이라 한도가 겹치지 않음
