- 막는 장치: `scripts/check-flicker.py` - 렌더 후 전 프레임 변화량을 재서 장면 경계가 아닌 튐을 찾는다. make-episode.sh에서 걸리면 멈춤

## 2026-10-20 유튜브 자동 더빙이 켜져 있음 (몽골 1편 qY1J4MPUUOw)
- 증상: 스튜디오 언어 페이지에 오디오 트랙이 21개 언어로 생김. 독일어·러시아어·아랍어·프랑스어·힌디어 등은 "게시 중", 시청 페이지 제목 아래에 "자동 더빙" 표시
- 스페인어: 우리 더빙 오디오가 없음(제목·설명만 게시). 대신 유튜브가 "스페인어(미국)" 자동 더빙을 만들고 있음
- 한국어: 사용자가 들어 보니 우리 더빙이 맞음. 그런데 트랙 ID가 자동 더빙 트랙들과 같은 `ko.10`으로 나와서 ID만 보고는 우리 것인지 구분이 안 됨 → 직접 들어서 확인
- 자막: 전부 자동 생성(asr)이고 우리가 올린 자막 파일은 없음
- 원인: 채널의 자동 더빙 허용이 켜져 있었음(기본값)
- 해결: 설정 → 채널 → 고급 설정 → 자동 더빙 → "자동 더빙 허용" 체크 해제 (업로드 기본 설정이 아님. 업로드 기본 설정의 제목·설명 칸은 새 업로드에 미리 채울 기본 문구라 비어 있어도 됨). 이미 생긴 자동 더빙은 언어 페이지 오디오 칸 메뉴에서 게시 취소/삭제. 스페인어 더빙은 직접 올림
