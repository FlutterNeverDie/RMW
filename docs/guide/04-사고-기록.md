## 2026-10-20 영상 내내 깜빡임 (몽골 1편)
- 증상: 사용자가 영상 전체에서 깜빡인다고 지적
- 원인 3가지
  1. 그림 장면에서 확대가 1.15배를 넘는 순간 objectFit이 contain → cover로 바뀌게 짜여 있어 화면이 툭 튐
  2. 큰 그림(최대 16MB)을 크롬이 다 그리기 전에 프레임을 찍어 빈 화면이 섞임
  3. transform scale로 2~3배 확대하면 크롬이 그림을 3×3 타일로 깨뜨린 프레임을 찍음
- 해결: 맞춤 방식 고정, `zoomBox`(transform 대신 실제 크기로 배치), 그림 2000px 이하·지도 JPG, `decoding="sync"`, `remotion.config.ts`에 `setChromiumOpenGlRenderer("angle")`
- 막는 장치: `scripts/check-flicker.py` - 렌더 후 전 프레임 변화량을 재서 장면 경계가 아닌 튐을 찾는다. make-episode.sh에서 걸리면 멈춤
