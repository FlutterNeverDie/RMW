## 화면
- 지도는 사이트 지도 캡처(`scripts/clean.mjs`), 그림은 위키미디어 공용 **퍼블릭 도메인만** - 출처는 `public/art/<시리즈>/credits.json`에 남기고 설명란에 자동 기재
- **지도 선명도 규칙 (2026-10-20):** 1440p로 찍으니 확대 배율 z는 `캡처 폭 ÷ 2560`을 넘으면 원본을 늘려서 흐려진다. `clean.mjs`는 배율 2로 찍으니 1920x1080 캡처 = 3840 폭 → z 1.5까지, 2560x1440 캡처 = 5120 폭 → z 2까지. 더 당겨야 하면 z를 키우지 말고 사이트에서 휠로 확대한 세트를 따로 캡처해 그 세트에서 z를 낮게 쓴다 (`mg-zoom`처럼)
- 긴 영상은 **1440p(2560×1440)로 렌더** (2026-10-20). 화면 배치는 1920×1080 그대로 두고 `make-episode.sh`가 `--scale=4/3`로 찍는다 - 유튜브가 1440p 이상은 VP9로 더 좋게 압축해 1080p 시청자도 선명. 렌더 시간 약 1.8배, 토큰 비용은 없음
- 렌더 프레임은 JPEG 화질 95 (`remotion.config.ts` `setJpegQuality`). 기본 80은 지도 선·글자가 뭉개짐
- **옛 그림 2.5D** (2026-10-21 사용자: 로컬·무료 AI 허용): `art` 장면에 `parallax`(세기, 0.04~0.08)를 주면 Depth Anything V2 Small(Apache-2.0, 로컬)로 그림의 깊이를 재고, 카메라가 그림 속으로 들어가듯 가까운 인물이 더 크게·빨리 움직이는 연속 그림을 만든다(`scripts/parallax.py`). 그림을 새로 그리는 AI가 아니라 원본 픽셀을 옮기는 것 - 퍼블릭 도메인 원칙 그대로. 시안 `~/hwm/시안/옛그림 2.5D.mp4`
- 딱 맞는 그림이 없으면 같은 시대·지역의 비슷한 그림으로 대신해도 된다 (사용자 OK)
- **화면 글자는 숫자·연도·기호만 (2026-10-21 사용자: 영어가 너무 많아 글로벌에 안 맞음)**. 한 화면을 모든 언어 더빙이 같이 쓰니 낱말·문장·이름은 넣지 않는다 - 말은 내레이션이 한다. 지도는 이름 없이 캡처(`NAMES=off`), 누가 누군지는 캐릭터 얼굴·국기·색으로. 대사 카드는 말하는 캐릭터 + 소리 막대 (이름 글자 없음). 대본 검사가 오류로 잡는다
- **빨간 띠 도장 글자("DEFEAT", "BEGTER" 등) 폐지** (2026-10-21 사용자: 오타처럼 보이고 개연성이 없음). 강조는 그림으로 - 깃발이 쓰러짐, 지도 색이 바뀜, 캐릭터 표정. 도장을 쓰면 숫자·기호만(1241, ✕), 한 편에 1~2번, 절정에서만

- 마지막 20초는 유튜브 최종 화면 자리(다음 편 + 구독 점선 칸). 실제 버튼은 스튜디오 → 최종 화면에서 얹는다

## 언어
- **더빙 길이는 영어의 110% 이하 그대로** (2026-10-21 사용자): 길이 검사가 실제 목소리 길이로 재게 바뀌자 걸리는 줄이 크게 늘었다(예전 1편 12 → 101줄) - 기준을 늦추지 않고 대본을 처음부터 짧게 쓴다. 더빙은 같은 뜻을 더 짧게 현지화하는 게 기본
- 영어(영상) + 한국어·스페인어(더빙 트랙). 장면 길이는 가장 긴 언어 기준이라 더빙 트랙 = 영상 길이
- 시청자용 문구(제목·설명·대사)는 **번역이 아니라 현지화** - 그 나라 유튜버 말투로 새로 쓴다. 직역·AI 같은 문장 금지 ("누가 이기고 있는지 한순간도 놓치지 않게" 같은 것)
- 사용자는 한국어만 직접 듣고 판단 가능 → 다른 언어는 현지화 검토 도장 + AI 음성 검수(`scripts/qa-voice.mjs`)
- 한국어 내레이션은 **해요체(~요/~죠)로 통일**. "~습니다"를 섞으면 어색함 (2026-10-20 사용자)
- 인물·지명 표기는 채널 공통 사전 `episodes/names.json` - 편마다 같은 표기. 스페인어 Gengis Kan처럼 나라별 관용 표기는 맞는 현지화
- **현지화 검토 하네스** (2026-10-20 사용자): 언어마다 `docs/guide/locales/<언어>.md` 가이드(말투·숫자·이름·금지 표현) 기준으로 Claude가 검토(`/localize`)하고 도장(`episodes/<편>/review/<언어>.json`)을 찍는다. 대사가 바뀌면 도장이 풀려 한 편 만들기가 멈춤 (`scripts/locale-review.py gate`). 스페인어는 중남미 중립(es-US 목소리), tú 통일
- 화면 글자를 줄이는 법: 지도는 `NAMES=off`로 이름 없이 캡처하고 필요한 이름만 라벨로, 도장은 낱말 대신 기호·연도·이름, 부제·제목은 이름·지명·연도만

## 브금·효과음
- 브금 14곡: `audio/make_bgm.py` (MIDI 작곡). 장면표(ep.json 장면)의 `music`에 곡 이름을 적으면 그 장면부터 그 곡이 반복 재생되고, 목소리 나올 때 0.3배로 자동으로 줄인다
- **곡 늘림 (2026-10-21 사용자: "브금 좋네 근데 더 다양해도 좋겠다")**: 10분 한 편에서 같은 소리가 되풀이되지 않게 분위기·빠르기·조·편성이 서로 다른 9곡 추가. 목관(플루트·오보에·클라리넷·바순)·글로켄슈필·마림바·튜뷸러 벨·독주 바이올린·튜바·팀파니 롤·약음 호른까지 VSCO 악기를 넓게 씀. 합창·타이코·샤쿠하치(예전 음원)는 새 곡에 안 씀. 반복용 곡은 끝을 처음과 이어지게(딸림화음이나 같은 크기로) 끝냄
- **곡 고르는 법 (`music` 값 -> 언제)**
  - `hook` - 첫 5초 쾅(7초, 반복 안 함). 영상 맨 앞 훅 장면에, 다음 장면에서 다른 곡으로 바꾼다. 메인 테마 머리(A-D-F)를 금관이 외침
  - `main` - 메인 테마(D단조 92). 도입·장 제목·채널 얼굴
  - `steppe` - 초원·유목(E 도리안 72, 손북 셋잇단·열린 5도·플루트·독주 바이올린). 유목민의 삶, 넓은 땅, 이동·원정 출발
  - `discovery` - 발견·경이(Eb장조 84, 하프·글로켄·플루트·첼로). 새 땅·도시·발명, 지도가 넓어질 때, 평화로운 번영
  - `intrigue` - 음모·수수께끼(B단조 96, 피치카토·낮은 클라리넷·바순). 궁정 암투, 배신 준비, 첩자, "그런데 이상한 점이..."
  - `tension` - 긴장(D 지속음 72, 심장 박동). 결전 직전, 위기가 다가올 때
  - `march` - 진군(C단조 104, 행진 스네어·트롬본·튜바, 점점 커짐). 군대 집결·행군, 세력이 커지는 과정
  - `chase` - 추격(F단조 150, 16분 스피카토·호른). 도망·추격, 빠른 기병전, 시간에 쫓기는 이야기
  - `battle` - 전투(D단조 138, 3+3+2·합창·타이코). 본격 회전·전면전
  - `siege` - 포위·공포(C# 60, 낮은 금관 덩어리 화음·팀파니 롤·징). 성 포위, 학살·역병, 압도적인 적
  - `triumph` - 승리(D장조 100 팡파르). 이긴 순간, 제국 성립
  - `aftermath` - 상처뿐인 승리·전쟁 뒤(G단조 63, 종·독주 바이올린, 승리 팡파르가 단조로). 승리의 대가, 폐허, 몰락의 시작
  - `lament` - 비가(D단조 64, 첼로 독주·합창). 죽음·이별·멸망
  - `outro` - 엔딩 화면(D장조 20초, 반복 안 함). 마지막 장면·구독 화면
  - 한 편 안에서 같은 곡은 2번까지, 이어지는 두 장은 다른 곡. 대사 많은 설명 구간은 `steppe`·`discovery`·`intrigue`처럼 가운데가 비어 있는 곡이 목소리를 덜 가린다

## 썸네일
- 1280×720, 왼쪽 지도 + 오른쪽 인물 + 띠 문구 + 큰 영어 2~4단어
- 스타일 A(빨간 띠 + 빨간 글자) · B(검은 띠 + 금색 글자) · C(빨간 띠 + 금색 글자). 어두운 세피아+세리프는 쓰지 않는다
- **같은 재생목록은 같은 스타일**, 시리즈마다 A·B·C를 돌려 쓴다. 몽골 제국 = A
- 편마다 같은 스타일로 문구만 다른 3개 → 1번 기본, 2·3번은 "테스트 및 비교"

## 기울인 지도 장면 (2026-10-21 사용자)
- 사이트 지도에 기울이기(0~55°)·360° 자유 회전이 생겼다. 영상에서는 땅을 눕혀 놓고 그 위에 기병·보병·탱크·참호선·화살표를 움직여 전쟁 양상을 보여 준다 (예: 수부타이의 거짓 후퇴와 양익 포위, 2차대전 전선)
- 사이트 개발 서버에서만 켜지는 장면 층으로 그리고, 시간을 1/30초씩 넘기며 한 장씩 찍는다(실시간 녹화 아님 - 끊김 없음). 장면 파일·캡처 스크립트·결과는 모두 RMW에 (공개 사이트 저장소에 유튜브 흔적 없음)
- 출력 2560×1440·30fps JPEG 95 연속 그림, 장면 안 시각은 0~1 비율 + 이름 붙인 시각(marks: 대사 순간에 맞춤), 화면 글자 없음, 아이콘은 캐릭터 그림체(먹선·바랜 색)
- 횟수는 정하지 않고 필요한 만큼 쓴다 - 품질이 가장 중요 (2026-10-21 사용자). 찍는 시간은 코드 몫이라 토큰이 들지 않음
- 사이트 쪽 작업은 `[map]` 세션 담당 - 형식(장면 JSON)은 두 세션이 합의한 것 (scripts/map-scene.mjs 머리 주석)
