# 제작 결정 (사용자 확정)

## 화면
- 지도는 사이트 지도 캡처(`scripts/clean.mjs`), 그림은 위키미디어 공용 **퍼블릭 도메인만** - 출처는 `public/art/<시리즈>/credits.json`에 남기고 설명란에 자동 기재
- **지도 선명도 규칙 (2026-10-20):** 1440p로 찍으니 확대 배율 z는 `캡처 폭 ÷ 2560`을 넘으면 원본을 늘려서 흐려진다. `clean.mjs`는 배율 2로 찍으니 1920x1080 캡처 = 3840 폭 → z 1.5까지, 2560x1440 캡처 = 5120 폭 → z 2까지. 더 당겨야 하면 z를 키우지 말고 사이트에서 휠로 확대한 세트를 따로 캡처해 그 세트에서 z를 낮게 쓴다 (`mg-zoom`처럼)
- 긴 영상은 **1440p(2560×1440)로 렌더** (2026-10-20). 화면 배치는 1920×1080 그대로 두고 `make-episode.sh`가 `--scale=4/3`로 찍는다 - 유튜브가 1440p 이상은 VP9로 더 좋게 압축해 1080p 시청자도 선명. 렌더 시간 약 1.8배, 토큰 비용은 없음
- 렌더 프레임은 JPEG 화질 95 (`remotion.config.ts` `setJpegQuality`). 기본 80은 지도 선·글자가 뭉개짐
- 딱 맞는 그림이 없으면 같은 시대·지역의 비슷한 그림으로 대신해도 된다 (사용자 OK)
- 화면 글자는 지명·연도·인물 이름만. **대사 글자는 넣지 않는다** - 화면을 모든 언어 더빙이 같이 쓰기 때문. 대사 카드는 인물 이름 + 움직이는 소리 막대
- 자막은 화면에 박지 않고 유튜브 자막 파일로
- 마지막 20초는 유튜브 최종 화면 자리(다음 편 + 구독 점선 칸). 실제 버튼은 스튜디오 → 최종 화면에서 얹는다

## 목소리
- 내레이터 **Chirp 3 HD Charon, 속도 1.07** (1.19는 사용자가 빠르다고 함 - 분당 약 160단어)
- 인물 대사는 **배역제**: `cast.json`의 16개 배역(왕·장군·악당·간신·촐싹이·주인공·현자·백성·전령·여왕·어머니·젊은 여성·여성 악당·소년 등)에 인물을 배정. 같은 배역 = 채널 전체에서 같은 목소리 → 시청자가 목소리로 성격을 알아본다
- 인물 대사는 Gemini TTS로 연기(무료 키), 한도가 막히면 Chirp로 대신
- 높낮이 후처리·울림 효과는 쓰지 않는다 (기계음·동굴 소리 - 04 참고)

## 언어
- 영어(영상) + 한국어·스페인어(더빙 트랙). 장면 길이는 가장 긴 언어 기준이라 더빙 트랙 = 영상 길이
- 시청자용 문구(제목·설명·대사)는 **번역이 아니라 현지화** - 그 나라 유튜버 말투로 새로 쓴다. 직역·AI 같은 문장 금지 ("누가 이기고 있는지 한순간도 놓치지 않게" 같은 것)
- 사용자는 한국어만 직접 듣고 판단 가능 → 다른 언어는 AI 음성 검수(`scripts/qa-voice.mjs`)
- 한국어 내레이션은 **해요체(~요/~죠)로 통일**. "~습니다"를 섞으면 어색함 (2026-10-20 사용자)
- 인물·지명 표기는 채널 공통 사전 `episodes/names.json` - 편마다 같은 표기. 스페인어 Gengis Kan처럼 나라별 관용 표기는 맞는 현지화
- 대본 검사 `scripts/check-text.py`(LLM 없이 규칙)가 한 편 만들기 첫 단계에서 말투·"이였"·화면 영어 낱말·틀린 이름 표기를 잡고 멈춘다

## 브금·효과음
- 브금 5곡: `audio/make_bgm.py` (MIDI 작곡 + fluidsynth + MuseScore_General.sf2). 장면표의 `music`으로 장마다 바꾸고, 목소리 나올 때 0.3배로 자동으로 줄인다
- 효과음: `audio/make_sfx.py` (제목 쾅·도장·바람·북·나무 토막)
- 장면 전환 바람 소리는 **화면 종류가 바뀔 때만, 20초에 한 번 이하, 작게**. 연도 넘김의 해마다 나무 토막 소리는 뺐다 (2026-10-20 사용자: "쓰르르륵" 거슬리고 너무 잦음)

## 인물 캐릭터
- 대표 인물은 캐릭터 그림으로 등장시킨다 (별별역사 방식). **Claude가 편마다 직접 그린다(SVG)** - Gemini 키·유료 그림 모델은 쓰지 않는다 (2026-10-20 사용자)
- 시나리오 → 등장인물 목록 → 캐릭터 그림 → 영상에서 움직임(숨쉬기·깜빡임·말할 때 입). 그림체는 채널 화면(지도·옛 그림)과 어울리게
- 인물마다 포즈 6개(정면·옆·화남·놀람·슬픔·기쁨)를 파이썬이 그림 - 토큰 안 씀. 장면표 `pose`, `facing: "left"`로 고름 (2026-10-20 사용자)
- 인물을 넣고 빼는 건 시나리오 단계(Claude) - 편집기는 위치·포즈만 다듬음. 이미 만든 영상에 인물을 넣는 건 의미 없음 (2026-10-20 사용자)
- 편집기 캐릭터 페이지에서 인물 하나씩 색·모자·수염·옷 등을 고치면 그 인물만 바로 다시 그림

## 썸네일
- 1280×720, 왼쪽 지도 + 오른쪽 인물 + 띠 문구 + 큰 영어 2~4단어
- 스타일 A(빨간 띠 + 빨간 글자) · B(검은 띠 + 금색 글자) · C(빨간 띠 + 금색 글자). 어두운 세피아+세리프는 쓰지 않는다
- **같은 재생목록은 같은 스타일**, 시리즈마다 A·B·C를 돌려 쓴다. 몽골 제국 = A
- 편마다 같은 스타일로 문구만 다른 3개 → 1번 기본, 2·3번은 "테스트 및 비교"
