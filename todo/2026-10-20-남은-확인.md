# 남은 확인 (2026-10-20 두 세션 인수인계를 합침)

> **확인이 끝나면 이 파일을 지운다** (`todo/`가 비면 폴더도). 결정과 규칙은 이미 `docs/guide/`에 있다 - 여기는 아직 못 해 본 것만.

먼저 `docs/guide/`를 읽는다. 이 맥에는 목소리·렌더 재료(`public/ep/`)가 없어서 아래를 못 해 봤다. 재료가 있는 컴퓨터에서(또는 목소리를 만든 뒤) 확인.

## 실제 재료로 시험할 것
1. **1440p 렌더**: `npx remotion render src/index.ts Mongol01 /tmp/t.mp4 --frames=0-30 --scale=1.3333333333333333` → `npx remotion ffprobe -v error -show_entries stream=width,height -of csv /tmp/t.mp4`가 2560,1440이고 글자·캐릭터 배치가 1080p 때와 같은지
2. **캐릭터·효과음 큐가 렌더에 들어가는지** (짧게 렌더해 보기)
3. **목소리 끝 지지직 하네스**: `.venv/bin/python -I scripts/check-voice.py <장면표>` - 실제 목소리에서 정상 대사를 잘라내지 않는지(오탐), 지지직을 잡는지. `cast.py tail`·`clarity` 수정이 실제 소리를 바꾸지 않았는지 들어 보기
4. **입 모양**: `.venv/bin/python -I audio/characters.py mouth <장면표>` → 편집기 미리보기에서 입이 목소리에 맞는지
5. **문장 단위 자막**: 편집기 왼쪽 "자막 파일" → 시간이 맞는지
6. **편집기 길이 어림**(글자 수 기준)이 실제 목소리 길이와 얼마나 다른지 - 크면 `editor/app.tsx`·`scripts/check-length.py`·`scripts/check-pacing.py` estimate 계수 조정 (세 곳 같게)

## 다시 만들 때 (사용자가 1·2편을 지우고 다시 만든다)
- `/episode`로 06 단계표대로. 1편은 지금 리듬 검사 오류 13·화면 검사 54·길이 12·대본 검사 53 - 새 대본에서 0으로
- 지도는 2560x1440으로 다시 캡처, 나라 이름이 많으면 `NAMES=off` 검토
- 1편 `meta.json`의 `"uploaded"`는 사용자가 유튜브에서 지울 때 같이 지움
- 다시 올릴 때: 한국어·스페인어 더빙 둘 다 올리고 언어 페이지에서 오디오 "게시됨" 확인, 언어별 `.srt`도
- 첫 API 업로드 때 확인: 언어별 제목(localizations)과 썸네일이 지금 권한(youtube.upload)으로 들어가는지 - 안 되면 스튜디오에서. `--dry-run`으로 내용은 확인됨

## 사용자에게 물어볼 것
- 썸네일 글자가 영어라 한국어·스페인어 시청자도 영어를 본다 - 언어별 썸네일이 필요한지 (유튜브가 언어별 썸네일을 지원하는지부터 확인)
