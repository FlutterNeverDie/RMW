### 3. 전환 효과음 줄임 (`src/episode/Episode.tsx` sceneSfx)
- 지도·그림 장면마다 붙던 바람 소리 → 화면 종류가 바뀔 때만, 20초 간격, 작게. 연도 넘김 나무 토막 소리 제거
- 장면 안 원하는 시점 소리 `cues: [{src, at, vol}]` 렌더 지원

### 4. 인물 캐릭터
- `characters.json`(설계, ko·about = 한국어 이름·하는 일) → `audio/characters.py build` → `public/chars/<id>/<포즈>/` 겹 SVG
- 포즈 6개: front·side·angry·shocked·sad·happy. 장면표 `char`, `pose`, `facing`, `charAt`(left·center·right)
- `src/episode/Character.tsx`: 숨쉬기·깜빡임·흔들림·입. 입은 `characters.py mouth`가 목소리 크기로 만든 `mouth.json`(make-episode.sh에 연결), 없으면 흉내
- 대사 카드(line)는 말하는 사람 캐릭터 자동, 지도·그림은 `char`로 세움. `char: "none"`이면 안 그림
- 지금 1편 인물 7명만 있음. **2편 인물(루수단 여왕, 수부타이, 쾨텐 칸, 므스티슬라프 등)은 설계 없음** - 대사 카드가 예전 모양(이름 + 소리 막대)으로 나옴
- 인물을 넣고 빼는 건 시나리오 단계(Claude가 장면표에)에서만. 편집기는 위치·포즈·방향만 (사용자 결정)

### 5. 편집기 `npm run editor` → http://localhost:4600 (AI 없음)
- `scripts/editor.mjs`(서버, `editor/app.tsx`를 esbuild로 묶음) + `editor/index.html`(스타일) + `src/preview.tsx`(그림·영상 뽑기용 진입점)
- 캡컷식: 가운데 영상(실제 Episode를 Remotion Player로 소리까지), 아래 트랙(화면·인물·효과음·브금·언어별 대사), 왼쪽 언어 타이밍·검사·자막 파일, 오른쪽 탭 대사·화면·소리·인물
- 소리 탭: 미리듣기, 트랙·영상에 끌어다 놓기, 내 파일 끌어오면 wav로 변환해 `public/sfx/my/`·`public/bgm/`
- 화면 탭: 카메라(시작·끝 x·y·확대) 슬라이더 + 확대 한도 경고(그림 폭 ÷ 2560), show JSON
- 우클릭 메뉴, ⌘Z/⇧⌘Z, ⌘S, Space, ←→, 한국어 툴팁
- 업로드한 편 잠금: `meta.json`에 `"uploaded"` → 화면·순서·길이·영어·인물 잠금, 미리보기도 인물 없이. 서버 저장에서도 확인
- 캐릭터 페이지(인물 탭 → 모습): 색·모자·수염·옷 바꾸면 그 인물만 0.2초에 다시 그림
- 색: 흑백 톤, 저장·재생만 라임색 (사용자 결정)
- **내역**: 저장할 때마다 저장 직전 장면표를 `episodes/<편>/.history/`에 남기고(git 제외), 편집기 "내역"에서 바뀐 것(옮긴 장면·바뀐 대사 전/후) 보기·되돌리기·저장 안 한 변경 버리기 (실수 방지 - 사용자 요청)

## 확인할 것 (이 맥에 목소리·렌더 재료가 없어 못 한 것)
1. **입 모양 맞추기**: 목소리를 만든 편에서 `.venv/bin/python -I audio/characters.py mouth episodes/<편>/ep.json` → 편집기 미리보기에서 대사 카드 입이 목소리에 맞는지
2. **문장 단위 자막**: 목소리 만든 편에서 편집기 왼쪽 "자막 파일" → `out/editor/<편>.<언어>.srt` 시간이 맞는지
3. **실제 렌더에 캐릭터·cues가 들어가는지**: `make-episode.sh`로 짧게 렌더해 확인 (1440p `--scale`과 같이)
4. 편집기 언어 타이밍의 "어림" 값(글자 수 기준)이 실제 목소리 길이와 얼마나 차이 나는지 - 크면 `editor/app.tsx` estimate 계수 조정
